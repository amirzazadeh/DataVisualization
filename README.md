# Data Visualization in R (Plots and Maps)

A practical guide to creating effective data visualizations in R using ggplot2 and spatial mapping tools. This repository focuses on clear communication, reproducible workflows, and applied examples.


---

## Learning objectives

By the end of this session, you will be able to:

- Apply the principles of effective data visualization
- Create common plots using R (ggplot2)
- Produce maps to present your data
- Use AI prompts to generate R code for different types of visualizations
- Build reproducible workflows in R
